# Receiz authority contract

Receiz is a proof-native artifact system. The sealed Receiz proof object carries authority. Public verification must verify the complete enclosing artifact under fixed canonical Receiz roots before projecting embedded payloads. A payload digest alone does not prove admission, ownership, identity, access, or Settlement.

Verified local truth remains immediately usable. Hosted routes, SDKs, MCP adapters, sessions, and display state remain beneath the proof object. Later verified truth may append; weaker representations cannot erase or replace stronger truth.

The disclosure checker in this preparation tree checks file inventory and SHA-256 integrity only. It does not implement the canonical verifier or authenticate any proof object, identity, ownership, Kai coordinate, Settlement, or release. Public extraction of those verification mechanics remains pending exact component approval and canonical release evidence.
