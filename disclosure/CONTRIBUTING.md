# Contributing

Build integrations through the published SDK, MCP, and AI skill interfaces. For documentation or interface feedback, provide the public package version, relevant contract, expected behavior, and a minimal synthetic example.

Propose changes with a focused pull request. Explain the user outcome and checks performed. Do not include private implementation, user artifacts, credentials, proprietary source excerpts, generated source maps, or deployment configuration.

Changes to inventoried disclosure files require a reviewed manifest update. A matching digest alone does not approve disclosure or authenticate a release. Do not add alternate issuers, testing roots, or replacement authority to make an example pass.

The repository remains preparation material with licensing pending. A contribution does not imply that proprietary Receiz implementation is available for redistribution.
