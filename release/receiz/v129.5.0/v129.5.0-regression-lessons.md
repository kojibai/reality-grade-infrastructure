## Why It Regressed

The failures crossed specific boundaries: source and representation, public identity and signing evidence, Original and display record, actual provider/financial event and a convenient projection, execution capacity and proof validity, or generated metadata and source. A successful hydrate, matching count, clean audit, passing component suite or claimed fix could conceal a different failing boundary.

Repeated whole-history work and new wrappers did not resolve the missing source relationship. A weaker readiness marker could not establish stronger truth. The correction is direct reuse of the implemented primitive, exact predecessor, retained artifact and existing exporter/executor. Each layer must retain its actual scope.

Package source, packed runtime, installed runtime, browser worker, downloaded bytes, first HTML, current deployment and historical attestation are different evidence coordinates. A pass at one cannot certify another. That lesson applies equally to main application, Bank, Academy, public disclosure and standalone verifier.

## Locked Rules

- **First admission only, then append forever.** Preserve stable object identity, original payload, custody, provenance, prior accepted history, unknown namespaces and exact KKS sequencing.
- **Representation never outranks source.** Complete held proof truth paints immediately; weaker network/session/database/capture state cannot replace it or delete local custody.
- **Use the actual Original.** Verify the enclosing source first; exports retain accepted bytes/signature/history. No display JSON, detached self-hash or reconstructed wrapper becomes Original authority.
- **Native identity remains native.** Account-entry freeze, device/PBI proof and recovered-account continuity stay intact. Optional enterprise service review creates no ordinary signing dependency.
- **Financial evidence remains exact.** Funding, quote, payment, bearer, claim, sale, history and current rights remain separate; preserve conservation and once-only effects.
- **Historical law remains immutable.** Distribution 129.5 does not rename 127 rules, historical schemas, roots, matrix, artifacts, content-addressed downloads, tags or signed records.
- **Actual evidence wins.** Contradictory screenshots, browser state or saved-file verification fail the work. Keep failed/interrupted records and append a later exact pass.
